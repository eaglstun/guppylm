Behind the glass
Aquarium v5.1 is a fork of GuppyLM, pretrained on TinyStoriesV2-GPT4, then trained on TinyDialogues and ocean conversations before sea-creature chats written by Claude Haiku and local Ollama qwen3-coder:30b. TinyStories windows stayed in the mix during both chat stages. This version completed 15,000 chat-training steps with four noun-swap copies per eligible dialogue. Its matrices and embeddings use int8 weights with one float32 scale per row; biases and LayerNorms stay float32. The model file is 9,042,320 bytes (9.04 MB), and inference runs in this tab with no server. Browser model details and experiment notes.
